# Coder

`CODER_CORE.md` defines a specification-execution role for one-shot or Run work. Dispatch names one task-specific `context.md` or its exact frozen copy. Coder translates its decided behavior, state, and processing rules into code and refuses with `contract_conflict` before implementation when a new decision is needed. Do not load the shared development standard as coder design authority. The project overlay supplies only execution bindings and preservation constraints, not another implementation specification.
