## Documentation authority

- The current source tree is authoritative for implementation claims.
- A project's HEAD system graph is a retrieval index for Feature and File relationships; it selects sources but does not replace them.
- Project-owned instructions are authoritative for product policy, repository boundaries, credentials, and integrations.
- Historical Run material explains how the system arrived here but does not override current source.
