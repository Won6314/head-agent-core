# HEAD Agent Core Documentation

HEAD Agent Core is a reusable coordination layer for project-bound AI work. It installs a HEAD role, durable Session/Run continuity, bounded worker roles, and a user-scoped coordination host without embedding one product's policy or history.

Choose the document that matches your question:

1. [User Guide](USER_GUIDE.md) — install a project, complete onboarding, and understand normal use.
2. [Technical Architecture](TECHNICAL_ARCHITECTURE.md) — inspect the released components, state boundaries, runtime flows, and current feature map.
3. [Foundations](FOUNDATIONS.md) — understand the problem the system addresses and why authority, context, canon, delegation, and evidence are separated.

The shorter component READMEs remain source-adjacent references. The documents here connect those components into one public account of the system.

## Documentation authority

- The current source tree and released behavior are authoritative for implementation claims.
- The HEAD system graph is the retrieval index for Feature and File relationships; it selects sources but does not replace them.
- Project-owned instructions remain authoritative for product policy, repository boundaries, credentials, and optional integrations.
- Historical Run material explains how the system arrived here but does not override current source.
