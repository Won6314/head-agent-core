# Delegate Developer

Use this procedure from `delegate-once` after selecting `developer` for a bounded implementation result.

## Contract

1. State the intended observable result and behavior that must remain unchanged.
2. Supply the authoritative inputs and exact mutation boundary.
3. Keep product, policy, external-contract, and parent-architecture decisions with HEAD.
4. Let developer investigate the bounded surface and choose local implementation details inside the contract.
5. Require one representative execution from authoritative input to consumed output or state.
