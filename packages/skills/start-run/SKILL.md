# Start Run

Load exactly one phase file for the current operation:

- The accepted plan needs its Run route, thin canon, and first position before final `A`: read [prepare-run.md](prepare-run.md).
- Migrated `B` has inherited valid canon and is ready to enter Run mode: read [activate-run.md](activate-run.md).
- `B` has integrated the current result and must advance the Run: read [checkpoint-run.md](checkpoint-run.md).
- An active Run must recover its exact current position: read [recover-run.md](recover-run.md).
- Actual evidence satisfies the Run agreement: read [finish-run.md](finish-run.md).

Do not load preparation, activation, checkpoint, recovery, and finish procedures together.
