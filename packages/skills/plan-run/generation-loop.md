# Generation Loop

## Trigger

Clean `a′` or an accepted generation has one identified planning gap before Run readiness.

## Exact reads

Read `a′`, the current cumulative accepted plan artifact, one identified planning gap, the exact existing Skill or support file that owns the method for that gap, only the authoritative sources that can change it, and `anchor-operations.md`.

## Authority

The current complete-context HEAD selects the method and judges fidelity. Existing Skills own their methods. Temporary children may elaborate within the Plan Contract but cannot alter user authority or promote themselves.

## Produced result

Repeat one coherent generation at a time:

1. Name the single gap whose resolution can materially advance Run readiness.
2. Select the exact existing method file and source files for that gap. Do not load unrelated phase files or the parent transcript.
3. Load the current accepted anchor in task mode without `save_as` and request one bounded candidate result. Use separate review children only when their independent judgment can change acceptance.
4. Re-anchor the handoff on the Plan Contract and cumulative accepted plan. Discard branch framing, method narration, and rejected alternatives.
5. If acceptance would change a locked decision, rejected interpretation, authority boundary, user-visible result, material architecture, cost, risk, success condition, or stop condition, return the decision to the user before acceptance.
6. Merge only accepted meaning into a new cumulative generation artifact.
7. Load clean `a′` with that exact cumulative artifact and save it as the next immutable generation with source `a′`. Do not promote the candidate session.
8. Continue this file only while another material planning gap remains. Do not create an anchor for a trivial wording change or an unaccepted branch.

## Mutation class

Disposable candidate/review tasks, accepted plan artifacts, and immutable accepted-generation creation. No production mutation.

## Next consumer

This file for one remaining planning gap, or `finalize-A.md` when the plan is ready.
