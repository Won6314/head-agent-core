# Dispatch

## Trigger

Persistent B has a prepared current Slice and any required scheduling decision.

## Exact reads

Read the prepared Slice, the selected worker readiness Skill, active Run identity, and current position. Do not reload plan generations or broaden the worker packet.

## Authority

Only active execution successor `B` may dispatch. The worker owns production, directly encountered correction, representative proof, and evidence-backed conflict return inside the Slice; it cannot amend the Slice or parent plan.

## Produced result

1. Confirm active Run mode and that the Slice is still current.
2. Dispatch the selected worker with the Slice and exact referenced sources; do not send the parent context.
3. Continue independent `B` work only when it cannot alter the dispatched contract or shared mutation surface.
4. Otherwise return control and wait for the terminal completion notification.
5. On completion, inspect the validated handoff and actual artifacts. Inspect live state or logs only for failure diagnosis or an explicit progress request.
6. Keep correction with the same worker while the Slice remains valid. A material contract conflict returns to `B` before further mutation.

## Mutation class

Worker task dispatch and lifecycle state.
