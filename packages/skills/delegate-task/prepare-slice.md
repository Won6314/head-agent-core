# Prepare Slice

## Trigger

The final planning HEAD or active `B` has selected one coherent Run result that needs an independently consumable owner contract.

## Exact reads

Read immutable plan authority (`A` when it exists), `run.md`, current position, only the relevant plan sections and direct evidence, plus the selected worker readiness Skill. Do not pass parent transcript, full ledger history, or unrelated source files.

## Authority

The current complete-context HEAD selects the worker before writing the Slice. For a fully decided Run implementation result, select `coder` and load `delegate-coder`; if the contract is not ready, return to planning. The worker owns local judgment only inside the completed contract.

## Produced result

1. Re-anchor on the whole Run and state why this result exists in that whole.
2. Define one behavior, artifact, or state that its next consumer can use without reconstructing worker reasoning.
3. Name the exact authoritative inputs and source paths.
4. Preserve locked decisions, mutation and preservation boundaries, interfaces, and parent-owned authority.
5. State the representative primary-path proof and the material conflict that must return to HEAD.
6. Write one owner-specific Slice. Keep connected diagnosis, production, correction, and proof with the same owner.
7. During final `A` preparation, stop after the Slice is ready; do not dispatch it.

## Mutation class

Slice artifact creation.

## Next consumer

`schedule.md` when multiple prepared results are independently ready. Otherwise final planning returns the Slice to `plan-run/finalize-A.md`, while active `B` proceeds to `dispatch.md`.
