# start-job

Run `SKILL.md` before planning, changing, making, or delegating work. It reads the request and existing sources, presents concise problem / goal / conditions bullets, and confirms the job with the user while reusing prior agreement. It then selects direct work, `delegate-once`, or `plan-run` by result independence and the need for ongoing whole-outcome judgment. Direct work retains problem-to-solution reasoning, reuse, minimality, and verification; delegation and Run procedures remain in their own skills.
