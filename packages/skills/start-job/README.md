# start-job

Run `SKILL.md` before planning, changing, making, or delegating work. It reads the request and existing sources, presents concise problem / goal / conditions bullets, and confirms the job with the user while reusing prior agreement. It selects direct work, a fresh agent, or a context fork by knowledge-transfer cost, the need to preserve context for later work, and whether the current context needs the task's details. A fresh agent receives the goal, necessary background and sources, and constraints; a fork receives only a clear goal because it already holds the background. A `current` fork is not used to review its own work, and cached input still costs. `delegate-once` handles one bounded assignment; `plan-run` retains its separate role for multi-stage whole-outcome judgment. Direct work retains problem-to-solution reasoning, reuse, minimality, and verification.
