# Activate Runner

## Trigger

An Accepted Plan Baseline exists and its Runner must replace active planning in the same logical Session.

## Authority

The Planner owns the migration boundary. The Runner can materialize and dispatch only selected Execution Contracts; saved-Planner checkpoint review owns acceptance and next-horizon judgment.

## Produced result

Migrate the Accepted Plan Baseline into one Runner in the existing mainline position, with rollback protection. Do not start Run mode, inspect field state, or dispatch work during migration. The Runner next uses [activate-run.md](../run/activate-run.md).
