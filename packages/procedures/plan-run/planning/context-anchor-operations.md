# Context Anchor Operations

## Trigger

Planning needs an immutable Problem Baseline, a clean planning context, or Runner activation.

## Authority

The Planner accepts material; a candidate, reviewer, or Worker cannot promote itself or change the Plan.

## Produced result

Save the Problem Baseline immutably. Load it for disposable outline, decomposition, review, or final-package work. Materialize each accepted planning generation only from its accepted whole plan. Materialize the Accepted Plan Baseline only from the user-approved final package. Migrate that baseline once to the Runner. Checkpoints update Run canon and do not create planning anchors.

## Next consumer

The active planning phase or Runner activation.
