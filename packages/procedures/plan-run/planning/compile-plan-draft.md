# Compile Plan Draft

## Trigger

The user has closed rich planning or is reviewing a proposed Plan Draft.

## Authority

The user accepts material decisions. The Planner compiles the transfer without resolving user-owned matters.

## Produced result

Compile the accepted intent, locked decisions, rejected interpretations, unresolved decisions, authority boundaries, success and stop conditions, and Problem Baseline dependencies into one Plan Draft. Materialize it as a clean planning context and present its whole-plan outline to the user. Acceptance makes it the initial accepted plan; a correction creates a new draft from the immutable Problem Baseline. Then use [refine-result-graph.md](refine-result-graph.md).
