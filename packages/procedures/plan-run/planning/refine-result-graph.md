# Refine Result Graph

## Trigger

An accepted Plan Draft has Results that can still be decomposed with current information.

## Authority

The Planner accepts the complete Result Graph. Part workers return only their assigned Result analysis.

## Produced result

Decompose by independent consumption and acceptance boundaries. A delegation-ready or execution-deferred Result must name its owned consumer result, interfaces or state meaning, mutation and rollback boundary where applicable, dependencies, and representative proof. Keep planning-deferred Results with their prerequisite and planning re-entry. Do not treat a Worker Report or Evidence as planning authority. When no Result remains decomposable, proceed to [accept-plan-baseline.md](accept-plan-baseline.md).
