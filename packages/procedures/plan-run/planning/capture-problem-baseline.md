# Capture Problem Baseline

## Trigger

Investigation is sufficient for planning and its material uncertainties are explicit.

## Authority

The Planner owns investigation sufficiency; the user retains material product, policy, architecture, cost, and workflow decisions.

## Produced result

Preserve confirmed facts, direct evidence, constraints, rejected directions, user decisions, and open material questions in an immutable Problem Baseline. The continuing Planner uses that baseline for rich planning and, after the user closes planning, proceeds to [compile-plan-draft.md](compile-plan-draft.md).
