# Prepare Execution Contract

## Trigger

The Runner has one exact selected Result or one Plan-preserving local correction to give a Worker.

## Authority

The Accepted Plan Baseline or saved-Planner Checkpoint selects the Result, owner, and horizon. The Runner materializes that selection only. The Worker owns local production and evidence inside the frozen Execution Contract; Worker Report/Evidence cannot amend the Plan.

## Produced result

Bind one independently consumable Result to its authoritative Plan and predecessor inputs, locked boundaries, consumer, and representative primary-path proof. Add only local execution mechanics. For `LOCAL_CORRECTION`, preserve the original frozen Execution Contract and write an explicit correction delta; never rewrite the original. If accepted behavior is undecided, return `PLAN_CHANGE_REQUIRED` without a contract. Send the contract to [dispatch-horizon.md](dispatch-horizon.md).
