# head-context 그래프 쓰는 법

이 그래프는 head-context 플러그인의 지도입니다. 플러그인이 하는 일, 그 일을 할 때 유저가 받는 글, 그 글을 만드는 코드가 서로 이어져 있습니다. 직접 열어 보는 용도가 아니라, 내 AI(Claude Code, Codex 등)에게 넘겨서 묻는 용도입니다.

## 준비

- Python 3 (따로 설치할 것은 없습니다)
- 이 폴더의 파일 셋: `head-context-0.9.5.sqlite`, `hc_graph.py`, `LLM.md`
- 코드 원문까지 보게 하려면: head-agent-core 저장소. 그래프는 commit `04e9328`(head-context 0.9.5) 기준입니다.

## AI에게 이렇게 말하세요

```
<이 폴더 경로>/LLM.md를 읽고, 그 안내대로 그래프를 조회해서 답해 줘.
질문: 저장 기능을 고치려면 어디를 봐야 해?
```

코드 원문까지 읽게 하려면 한 줄을 더합니다.

```
코드는 <head-agent-core 저장소 경로>에서 commit 04e9328 기준으로 읽어.
```

## 이런 걸 물을 수 있습니다

- 저장 기능을 고치려면 어느 함수를 봐야 해?
- 이 함수를 바꾸면 무엇이 영향을 받아?
- /clear 뒤에 하던 일로 돌아오는 건 어떤 글과 코드로 돼?
- 이 동작은 정해진 규칙이야, 아니면 그냥 그렇게 된 거야?

## 알아 둘 것

- 그래프는 0.9.5 기준입니다. 그 뒤에 바뀐 코드는 들어 있지 않습니다.
- "이걸 바꾸면 무엇이 영향을 받나"에 나오는 유저가 받는 글 목록은 후보입니다. 그 기능이 내는 글 전부를 보여 줍니다.
- 유저가 하는 일은 Claude Code로 실제로 써 보고 썼습니다. Codex와 OpenCode 쪽은 코드만 보고 썼습니다.
