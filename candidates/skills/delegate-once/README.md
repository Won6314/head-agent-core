# delegate-once

Load `SKILL.md` after HEAD has formed and retained the whole-outcome context and selected one decided kind of work. Keep investigation, design, implementation, and review in separate assignments: the worker returns its result, and HEAD decides the next task. Never delegate "investigate, then fix it." When `developer` is selected, load `../../procedures/delegate-once/workers/developer.md` as the execution-contract branch within this single-task boundary.
