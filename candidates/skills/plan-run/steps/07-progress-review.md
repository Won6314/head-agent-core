# 07 — P0 전체 진행 점검

현재 전체 기준 `P0_ID`에서 분기한다. 일반 검수는 Pn이 맡았고, 여기서는 전체적으로 잘 나아가고 있는지 본다.

## 호출 — context_run

```json
{
  "source_id": "{P0_ID}",
  "command": "너는 전체 목표를 보존한 P0에서 이미 포크된 전체 진행 점검 세션이다. 지금까지의 결과 {RESULT_REF}와 Pn의 판단 {PN_RESULT_REVIEW_FILE}을 보고, 이 진행이 정말 전체적으로 괜찮은지, 원래 목표를 향해 잘 나아가고 있는지 판단하라. 쓸데없는 규격화·절차·도구·작업을 늘리거나 수단 자체가 목적이 되지 않았는지, 접근 방향을 바꿀 필요는 없는지 보라. 일반적인 결과 검수를 반복하기보다 전체 진행에 대한 판단과 이유를 {P0_PROGRESS_REVIEW_FILE}에 정리하라.",
  "completion_note": "현재 단계: P0 전체 진행 점검. 다음 처리: Pn의 검수 맥락에 판단을 반영해 보완·다음 방향·완료를 정리. 레퍼런스: plan-run / steps/07-progress-review.md."
}
```

## 알림을 받으면

P0 판단을 [08 재통합·다음 방향](08-next-direction.md)에 전달한다. 기존 합의 밖의 전체 목표·조건 변경이면 먼저 사용자와 맞춘다. 이 P0 리뷰 child를 다음 Pn이나 기획 출발본으로 자동 승격하지 않는다.
