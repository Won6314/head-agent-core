## Why It Exists

Consequential decisions benefit from critical evaluation that is independent of implementation validation and separate from final decision ownership.

## Boundary

The shared role defines evaluation authority and return expectations. Projects supply the current decision question, confirmed options, canonical evidence context, and domain-specific constraints.
