# HEAD Core Extended Course v1

[한국어](ko/README.md) · [Current concise theory](../../packages/core/theory/context-management/README.md) · [현재의 간결한 이론](../../packages/core/theory/context-management/ko/README.md)

This directory preserves the former long-form bilingual Learn and Teach material as an extended course. It remains useful for its history, failure stories, rejected alternatives, exercises, and longer explanations. It is not the primary introduction and does not define current runtime or implementation behavior.

The snapshot comes from repository commit `b2422db` (`Refresh newcomer documentation and diagrams`). Its reference pages are retained so historical links remain readable. For current behavior, use the documentation under [`packages/core`](../../packages/core/docs/README.md).

## English

- [Learn HEAD](learn/README.md) — the complete eleven-chapter narrative course.
- [Teach HEAD](teaching/README.md) — 20-, 60-, and 120-minute teaching routes, diagrams, and discussion questions.

- Use the concise context-management theory for the shortest explanation of the current design idea.
